### 입출력 형식
- 입력
    - 로또 구입 금액 입력받음
    - 쉽표를 기준으로 당첨 번호를 입력받음
    - 보너스 번호를 입력받음
- 출력
    - 발행한 로또 수량 및 번호를 오름차순으로 출력([]안에 쉼표를 기준으로)
    - 당첨내역 출력
    - 수익률 출력
    - 에러 문구는 [ERROR]로 시작함

### 구현할 기능 목록
- 입력
    - [x] 로또 구매 금액 입력 받기
    - [x] 로또 당첨 번호 입력 받기
    - [ ] 보너스 번호 입력 받기
- 출력
    - [x] ‘구입금액을 입력해주세요.’ 출력하기
    - [x] 구매한 복권 개수 알려주기
    - [x] 구매한 복권 번호 알려주기
    - [ ] ‘지난 주 당첨 번호를 입력해주세요.’ 출력하기
    - [ ] 당첨 통계 출력하기
    - [ ] 수익률 출력하기
- 기능

    - [ ] 숫자를 쉼표 기준으로 분리하기
    - [x] 구매한 복권 개수 구하기
    - [x] 복권 번호를 발행해주기
    - [x] 발행한 복권 정렬
    - [ ] 당첨번호와 각 복권의 번호가 몇 개 일치하는지 확인
    - [ ] 수익률을 계산하기

### 예외처리

- [ ] 구입 금액이 1000으로 나누어 떨어지지 않음
- [ ] 금액을 입력하지 않음
- [ ] 금액이 숫자가 아님
- [ ] 금액이 양수가 아님
- [ ] 번호를 쉼표 기준으로 구분하지 않음
- [ ] 번호를 입력하지 않음
- [ ] 번호가 숫자가 아님
- [ ] 번호가 6개가 아님
- [ ] 번호가 중복됨
- [ ] 번호가 1~45사이의 숫자가 아님
- [ ] 보너스번호를 입력하지 않음
- [ ] 보너스 번호가 숫자가 아님
- [ ] 보너스번호가 로또 번호와 중복됨
- [ ] 보너스번호가 1~45사이의 숫자가 아님
